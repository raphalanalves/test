# Skills de Instagram da Malvora

Cópia das 9 skills de https://github.com/sergebulaev/instagram-skills (MIT, commit 652be40),
instaladas para o Claude Code usar automaticamente neste repositório.

- `ig-*/`: as skills (caption, carrossel, plano da semana, hashtags, humanizer etc.).
- `../references/`: regras compartilhadas. `voice-profile.md` foi preenchido para a Malvora em PT-BR.

Não foi copiada a pasta `lib/` (publicação via Publora, imagens via Pixfaro, dados via Apify, todos pagos).
Sem ela as skills funcionam no modo rascunho: entregam o texto pronto e a arte é feita no Canva.

- `../references/estruturas-de-retencao.md`: regra da Malvora para Reels (5 estruturas de retenção e checklist), estudada em 09/11/2026.
- `../references/gancho-curiosidade-ponte.md`: estrutura de anúncio/e-mail curiosidade → princípio → ponte → oferta, estudada em 09/11/2026.
